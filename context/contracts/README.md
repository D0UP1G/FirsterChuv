# Запросы изменения контрактов

Совместимая реализация [v1](../../docs/architecture/parallel-contracts.md) не требует нового согласования. Сюда добавляется отдельный файл `<agent>-<topic>.md`, если нужно несовместимое изменение: текущая версия/поле, предлагаемый контракт, причина, потребители, migration/совместимость, затронутый подпункт и независимая работа на время решения.

Каждый пишет свой файл; документы в Git не являются распределённой блокировкой. Не копировать запрос в STATE как готовое решение и не останавливать всю дорожку из-за одного CONNECT. Изменение реестра общих контрактов — короткий согласованный PR, владельцы доменов проверяют свои consumers.

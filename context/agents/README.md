# Карточки четырёх агентов

| Агент | Зона | Карточка |
|---|---|---|
| 1 | Платформа, аккаунты, турнирное CRUD, интеграция, запуск | [agent-1.md](agent-1.md) |
| 2 | Сетка, состояние матча, результат, события и SSE backend | [agent-2.md](agent-2.md) |
| 3 | Задачи, код, очередь посылок, judge и внешняя интеграция | [agent-3.md](agent-3.md) |
| 4 | Все пользовательские интерфейсы, редактор и зрительская карта | [agent-4.md](agent-4.md) |

Задачи и зависимости находятся в `ROADMAP.md`. Карточка отражает фактический статус автора: `TODO`, `IN_PROGRESS`, `BLOCKED`, `IN_REVIEW`, `DONE`. `DONE` означает, что результат интегрирован в `develop` и критерии задачи подтверждены.

Каждый агент редактирует только свою карточку. Чтобы передать задачу, сначала записать аудит, указать принимающего агента и последний SHA; затем новый владелец обновляет свою карточку. Чужая задача не становится свободной только потому, что её ветка ещё не опубликована.

Изолированный checkout обязателен при одновременной работе. Изменения собственных карточек видны всем после публикации/слияния, поэтому назначение и ветки нужно заранее сообщить координатору. Документы в Git не являются распределённой блокировкой файлов.

## Решения и отклонения

Не добавлялся endpoint `/api/v1/` только ради 200: контракт пока не назначает API root resource. Неизвестные API пути теперь получают корректный JSON 404. Compose `web`, `match-clock`, `judge-worker` остаются scaffold до появления frontend и management commands владельцев.

Deploy check не включает HSTS/redirect без известной TLS конфигурации; это ответственность проверенного внешнего proxy. В Django добавлен clickjacking middleware без инфраструктурных допущений.

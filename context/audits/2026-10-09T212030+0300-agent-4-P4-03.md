## Решения и отклонения

Производственный UI делает HTTP запросы и показывает ошибку интеграции при отсутствующем endpoint; он не включает fixture fallback. Синтетическая симуляция требует одновременно dev build и явного `scenario=match-ui`. API proposal оставлен отдельно до согласования/интеграции владельцами API. Новый backend контракт или общая схема не менялись.

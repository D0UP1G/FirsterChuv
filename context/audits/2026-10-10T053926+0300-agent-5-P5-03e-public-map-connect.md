## Выполненные изменения

- `frontend/src/api/client.ts`: `api.publicMatchSnapshot(matchId)` читает `GET /public/matches/{id}`; ответ валидируется существующим `validatePublicSnapshot` перед использованием.
- `frontend/src/spectator/transport.ts`: HTTP-транспорт читает реальный снимок; `subscribe` опрашивает снимок раз в 4 секунды (интерим вместо SSE): один `onOpen`, `onResync` только при смене `lastEventId`, при ошибке один `onError` и остановка опроса (страница сама переподключается); для прямой ссылки `/watch/:tournamentId/matches/:matchId` карта из одного матча собирается только из публичных полей снимка (имена, статус, победитель, без `userId`); без ссылки на матч остаётся честный отказ.
- `frontend/src/spectator/SpectatorMapPage.tsx`: `transport.bracket(tournamentId, matchId)` получает идентификатор матча при загрузке и при resync.
- `frontend/src/spectator/transport.test.ts`: 7 тестов (было 2): реальный URL и строгая валидация, карта одного матча без приватных полей, отказ 409, опрос и resync по курсору, остановка после ошибки, dev-сценарий.

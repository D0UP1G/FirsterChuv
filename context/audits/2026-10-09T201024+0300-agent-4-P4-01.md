## Выполненные изменения

- Создана SPA `frontend/` на React/TypeScript с Vite, React Router, lockfile, typecheck/lint/test/build командами и локальной инструкцией запуска.
- Настроен Vite dev server на `localhost:8080` с proxy `/api` и `/health` к backend `localhost:8000`; локальный origin совпадает с CSRF allowlist.
- Реализован единый API client с `credentials: include`, `Cache-Control: no-store`, сериализацией JSON, CSRF header, совместным ожиданием bootstrap-token, обработкой error envelope и ротацией токена на login/logout.
- Добавлен auth context с восстановлением сессии через `/me`, login/register/logout, устранением race при проверке сессии и сбросом in-memory user state после выхода.
- Добавлены маршруты главной страницы, входа, регистрации, публичного просмотра, кабинета и admin shell. Только private-маршруты требуют сессию; admin navigation показывает серверную роль. `next` ограничен same-origin.
- Добавлены состояния загрузки, ошибки с retry, empty state, доступные подписи форм, plain-text ошибки, skip-link и адаптивное оформление. Иллюстрация карты явно помечена схемой и не выдаёт фиктивный вердикт за live-событие.
- Добавлены API-client, auth-state и route tests; документация запуска находится в `frontend/README.md`.

Изменены только файлы `frontend/**`, карточка Agent 4 и этот новый аудит. Backend, чужие ветки и общие runtime endpoints не менялись. Архитектурные решения не изменялись.

## Решения и отклонения

Для dev proxy выбран `localhost:8080`, потому что эта точка уже указана в backend `CSRF_TRUSTED_ORIGINS`; API остаётся same-origin для браузера. Регистрация завершается экраном успеха, затем пользователь входит отдельно: текущий backend register не создаёт сессию. Демо-карта не содержит имён, счёта или вердиктов; это исключает фиктивный runtime-result.

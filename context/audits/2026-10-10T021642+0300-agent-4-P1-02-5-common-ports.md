## Изменения

- В `backend/apps/common/contracts.py` добавлены frozen/slots `InfrastructureFailureReceipt(submission_id, run_id, reason_code, retryable)` и `RunProblemSnapshot(run_id, problem_id, problem_version, problem_checksum)`.
- Добавлены `InfrastructureFailureSink.record_infrastructure_failure(receipt) -> None` и `RunProblemSnapshotProvider.resolve(run_id, problem_id) -> RunProblemSnapshot`.
- Описания закрепляют границы: failure содержит только серверный allowlisted code, не диагностику/вердикт; checksum относится к нормализованной задаче; snapshot берётся по assignment запрошенного run.
- `scripts/check_contract_imports.py` требует четыре новых публичных имени при проверке изоляции imports. Common tests фиксируют поля/frozen свойства новых DTO, сигнатуры новых ports и исходные поля трёх существующих receipt/permit.
- Изменены только common contracts/import check/common tests, своя карточка и этот audit. Нет optional-app import, миграций, URL/API, producer/consumer runtime, verdict changes или чужих файлов. Не менял `context/STATE.md`.

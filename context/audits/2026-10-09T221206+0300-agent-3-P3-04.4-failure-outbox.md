- Добавлена модель `InfrastructureFailureOutbox` и submissions migration `0002_infrastructurefailureoutbox.py`: one-to-one по submission, pending/sending/sent, bounded lease, attempt count, retry date и безопасный error code.

- Обновлён `backend/apps/submissions/README.md` с retry/fail-closed ограничениями.
- Добавлен contract request `context/contracts/agent-3-run-problem-snapshot.md` со статусом `WAITING_CONNECT`; он описывает нужные trusted `problem_version`/`problem_checksum`, owners, consumers и fail-closed fallback, не назначая A2 API.

## Решения и отклонения

- Реализован автономный A3 failure outbox из разрешённой задачи; общий common DTO/Protocol, A2 ledger и runtime provider не добавлялись.
- Snapshot contract оформлен запросом, поскольку `SubmissionPermit` и текущий A2 runtime не предоставляют immutable version/checksum. Не придумывался endpoint или формат запроса.
- Production worker требует оба настоящих sink. Пока snapshot/failure provider не подключены, этот кодовый срез не делает runtime готовым.
- Merge/switch/push/PR не выполнялись. Открытые PR #15/#16/#21/#23/#25/#26 и чужие worktree не менялись.

## Блокеры и риски

- Нужны A1 common failure receipt/protocol и A2 идемпотентный accepted-ledger technical transition; отсутствие реального sink пока оставляет worker fail-closed.
- Нужен A2 immutable run/problem snapshot provider или согласованная boundary для `problem_version`/`problem_checksum`; до этого LocalJudge не может безопасно загрузить задачу именно принятого run.
- Другие A3 READY workstreams P3-03, P3-02 и P3-05 уже имеют открытые PR #21/#23/#25/#26 и связанные feature worktree; эту сессию не расширял на чужую работу.

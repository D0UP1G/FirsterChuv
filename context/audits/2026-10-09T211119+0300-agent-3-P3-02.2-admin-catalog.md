## Решения и отклонения

Новый route — только admin catalog из уже сохранённого внутреннего `ProblemBundleV1`; существующий `POST /problem-imports` для official package не переинтерпретирован. Общий `CompetitionGatewayV1`/`WorkspaceContext` не менялись. Contract request создан по правилу `context/contracts/README.md`; statement/assets/languages нельзя связывать с active latest без run-pinned version.

## Блокеры и риски

- Import upload/status API не реализован в этом срезе. На актуальной `develop` ещё не находится parser hardening из отдельного PR #25; прежде чем вызывать `parse_problem_bundle` из runtime HTTP importer, требуется интеграция P3-02.3 или независимая проверка malformed manifest на этой ветке.
- Task selection и match workspace authorization зависят от persistent A2 run/tournament assignment providers, которых эта app не владеет.
- `context/contracts/agent-3-workspace-problem-version.md` ждёт ответа A2/команды; до него workspace выдача остаётся fail-closed/не реализована.
- Official package README не предоставлен; P3-06 остаётся `WAITING_EXTERNAL`.

## Решения и отклонения

Retry ограничен распознанными SQLite BUSY/LOCKED primary/extended error codes и штатными SQLite lock messages; произвольные ошибки не преобразуются в retryable status. Retry повторяет transaction целиком, не продолжает работу внутри транзакции с невалидным SQLite snapshot. PR #21 не сливался, чужие feature refs/worktree не менялись.

## Блокеры и риски

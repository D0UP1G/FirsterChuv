## Цель и исходное состояние

ROADMAP P4-05 требует публичную bracket/match map без login wall, двух игроков, прогресса по всем задачам независимо от порядка решения, попыток/verdict, лидерства/штрафа/таймера, projector и устойчивого отображения публичного потока. По `docs/architecture/realtime.md` сначала загружается snapshot, затем поток читается с cursor; повторы не должны повторно менять счёт/анимацию; resync перечитывает snapshot. `contracts/mvp-v1/public-match.json` задаёт allowlist безопасного match DTO. На исходном `develop` нет интегрированных PublicAccess и HTTP/SSE endpoints, поэтому production transport оставлен fail-closed, а синтетический transport доступен только в явном dev scenario.

## Выполненные изменения

- `frontend/src/App.tsx`, `frontend/src/App.test.tsx`: lazy anonymous routes `/watch/:tournamentId` и `/watch/:tournamentId/matches/:matchId`, projector shell; тест проверяет anonymous состояние с `/me` → 401 и скрытие основной навигации в projector mode.

- `frontend/src/spectator/reducer.ts`: snapshot/event cursor, run isolation, dedupe, authoritative score updates, resync на пропуск/неизвестное сопоставление пользователя с событием; анимации строятся только из принятых authoritative событий.
- `frontend/src/spectator/transport.ts`, `devTransport.ts`: production без публичного API возвращает недоступность; fixtures загружаются только через `?scenario=public-map` в DEV-сборке и удалены из production bundle.
- `frontend/src/spectator/SpectatorMapPage.tsx`, `spectator.css`: сетка и две дорожки прогресса, независимые checkpoints, задачи/attempts/verdicts, лидер и scoring explanation, penalty, монотонный countdown, stale/reconnect/resync, projector layout.

Общие API contracts, backend, migration, event schema и `context/STATE.md` не изменялись. Публичный bracket DTO является только локальной UI projection; отсутствующий backend contract не объявляется серверным контрактом.

- V03: reducer/test coverage проверяет dedupe, cursor gap, run mismatch и resync; dev transport демонстрирует обновления. Настоящие HTTP snapshot/SSE/`Last-Event-ID`, heartbeat, reconnect браузера к серверу и event-store recovery отсутствуют в интегрированном `develop`, поэтому T17 частично.
- V04: projector проверен интеграционным UI тестом и просмотрен в локальном браузере; обычные header/footer скрываются.
- T16: anonymous route проверен `App.test.tsx` с неавторизованным ответом 401; локальный браузерный сценарий подтвердил рендер сетки и projector, но использовал уже существующую авторизованную browser session. Реальный anonymous endpoint и runtime map не проверены.
- T20: UI не запрашивает source/email/compiler diagnostics, а strict allowlists закрываются при неизвестных/private полях. SQL/CSRF/IDOR/hostile browser/API matrix и фактическая конфиденциальность сервера этим срезом не закрыты.

## Решения и отклонения

Подключение настоящего HTTP/SSE отложено по зависимости ROADMAP: PublicAccess A1 и P2-06 должны попасть в develop. Не использовались открытые чужие feature branches/PR как production dependency. Для событий, где v1 не устанавливает эквивалентность `playerId` и public `userId`, клиент запрашивает authoritative snapshot вместо угадывания lane. Public bracket DTO не добавлялся в общий schema без подтверждённого provider contract.

## Блокеры и риски

P2-06 Public HTTP/SSE и A1 PublicAccess не интегрированы; для runtime CONNECT нужны snapshot/bracket endpoint, поток с корректным cursor/resync и фактический публичный DTO. Пока они отсутствуют, production показывает unavailable/error и не подменяет API fixtures. Реальные T16/T17/T20 остаются partial.

- `S02`: inactive users не могут войти; private `/me` требует session; logout инвалидирует session; cookies и private responses защищены.

- Для production rate limiting сейчас используется process-local DRF cache; Compose запускает один API process. Масштабирование потребует shared cache и проверки реальной proxy chain.

## Решения и отклонения

После успешного login возвращается новый `csrfToken`, так как Django ротирует CSRF secret при создании session. Rate scopes: `auth_login=10/minute`, `auth_register=20/hour`; текущий один trusted proxy hop задаётся `NUM_PROXIES=1`. Это соответствует текущему Compose, но не объявляется универсальной production proxy конфигурацией.

Роль `admin` не возвращается из public регистрационного DTO и не может быть передана клиентом. Initial admin command относится к A1-02.3 и ещё не добавлена.

# Аудиты рабочих сессий

Каждый агент создаёт отдельный Markdown-файл по [шаблону](_template.md), даже если сессия закончилась блокером. Формат имени: `2026-10-09T130000+0300-agent-3-A3-01.md`. Время и часовой пояс в заголовке обязательны.

Аудит фиксирует работу, которую агент действительно выполнил. В нём должны быть изменённые пути, задача и ветка, исходный SHA, проверки с результатами, ограничения и следующий шаг. Пользовательский код, токены и пароли в аудит не копируются.

Новую запись добавлять в feature-ветку вместе с её изменениями. Перед коммитом заполнить проверки; после получения PR добавить его URL отдельным завершающим коммитом или записью передачи. Не пытаться вписать SHA коммита внутрь самого этого коммита: достаточно SHA базы, ссылки на PR и диапазона Git в следующем аудите.

Для быстрых поисков использовать ID задачи или имя агента. Старые аудиты не являются доказательством состояния новой версии: проверять SHA, ветку и дату.

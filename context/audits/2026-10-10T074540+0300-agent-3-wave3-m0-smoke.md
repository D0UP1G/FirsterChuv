## Решения и отклонения

`--demo-import` выключен по умолчанию, поэтому прежний smoke flow не меняется. `PASS` означает только успешное выполнение нормализованного импорта в временную БД; `NOT_READY` остаётся фактической готовностью задачи и не маскируется как usable demo problem.

## Блокеры и риски

- Нет доступного Docker Engine/Compose; невозможны one-command runtime, настоящий компилятор и контейнерный verdict.
- В `cpp20` остаётся `verified=False`, поэтому импортированная задача не становится `READY`.
- Не проверены production worker → durable result/failure → score цепочка и browser M0 на одном SHA.

## Решения, ограничения и следующий шаг

Secret env injection должна назначаться только процессу команды: не класть значение в общий `.env` или env API и не указывать inline вместе с командой. Интерактивный ввод — предпочтительный путь для ручного bootstrap. Bootstrap может быть повторно вызван для существующего admin только как безопасный no-op; он не предназначен для смены роли/сброса пароля.

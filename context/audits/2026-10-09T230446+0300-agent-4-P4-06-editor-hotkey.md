## Цель и исходное состояние

Исходный кейс, `docs/requirements.md` и ROADMAP Agent 4 требуют доступный редактор с реальным вводом и Ctrl/⌘+Enter submit hotkey, без редактирования или отправки при закрытом/disabled editor. P4-04 UI уже интегрирован; этот срез не зависит от backend provider.

## Выполненные изменения

- `frontend/src/workspace/CodeEditor.tsx`: custom `Mod-Enter` keymap поднят до `Prec.highest` перед `basicSetup`; callback выполняется только когда editor enabled и callback задан.
- `frontend/src/workspace/CodeEditor.test.tsx`: новый test проверяет доступный CodeMirror textbox и callback при typing, Ctrl+Enter submit и read-only editor, который не меняет source и не запускает submit.
- `context/agents/agent-4.md`: добавлена сверка E01/T13 и точные границы.
- `context/STATE.md`, API contracts и backend не изменялись.

Первый test draft выявил ошибки harness: `userEvent.type` считал literal `{}` syntax key descriptor, а без явного `cleanup()` предыдущие CodeMirror DOM roots оставались между tests. После исправления focused case воспроизвёл product bug: `basicSetup` уже binding'ит `Mod-Enter` на `insertBlankLine` и срабатывал раньше нашего keymap; в read-only режиме этот binding отказывал и отдавал событие submit callback. `Prec.highest` и explicit disabled guard устранили обе стороны дефекта.

## Сверка с кейсом

## Выполненные изменения

- Создана собственная app `backend/apps/drafts/`: `Draft` и `DraftRevision`, миграция, приватный storage service, CAS по expected revision, SHA-256 принятых исходников, размер source ограничен 32 KiB UTF-8.
- Service принимает общий `WorkspaceContext` и требует `read_draft`, `write_draft` или `read_history`. Отсутствующий draft не сериализуется как revision 0/`updatedAt: null` вопреки `draft.json`: GET возвращает 404; первая запись с `expectedRevision: 0` создаёт revision 1. Конфликт первой записи возвращает `currentDraft: null`, если серверного сохранения ещё нет.
- Добавлены GET/PUT routes v1 с активной participant/session/CSRF проверкой, авторизацией через `WorkspaceAccess`, защитой от IDOR, 404 при отказе доступа и `no-store`/`no-referrer` для ответов с draft. Admin/spectator не получают source. Если production factory не настроена, API закрывается с 503; test adapter находится только в tests.
- Зарегистрированы только собственные AppConfig и route include. В `docs/architecture/data-model.md` задокументирована private revision history и CAS.
- Добавлен `context/contracts/agent-3-private-draft-get.md` со статусом `PROPOSED`: HTTP таблица указывает languageId, но не объясняет, как GET выбирает run; common A2 gateway требует runId. Предложены query selector и 404 для отсутствующей записи. Это не принятое решение, не правка общего API документа и не доказательство browser acceptance.
- Обновлена карточка agent 3. Upstream изменения в `context/STATE.md` пришли из merge `origin/develop`; собственных правок в STATE не вносилось.

## Решения и отклонения

- После PR #17 заменён локальный дублирующий контекст общим `WorkspaceContext`; core проверяет точные v1 actions.
- Нельзя выдавать несоответствующий `draft.json` пустой response с revision 0 и null timestamp, поэтому отсутствие storage row обозначено 404. Совместимость этой детали вынесена в proposal.
- GET `runId` selector пока остаётся неразрешённой contract clarification. Запрос приложен для review; не менять общие contract/schema files до решения.
- Production authorization не заменён mock-данными и fail-closed до настоящего A2 adapter.

## Блокеры и риски

- `context/contracts/agent-3-private-draft-get.md` ожидает review; P4-04 не должен считать GET query полностью согласованным до решения.

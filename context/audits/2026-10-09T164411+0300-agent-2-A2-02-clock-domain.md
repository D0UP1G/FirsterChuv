# A2-02.1 — независимое ядро часов матча

## Результат

Добавлен framework-independent clock domain в `backend/apps/competition/domain/clock.py`. Он считает активные миллисекунды с учётом пауз, переводит READY → RUNNING → PAUSED → RUNNING, возвращает серверное elapsed для допуска посылки и идемпотентно переводит истёкший RUNNING в FINALIZING. Равенство дедлайну уже закрыто: принимается только `elapsed_ms < allowed_duration_ms`; паузой нельзя продлить уже истёкший run.

Срез не связывает run с задачами, не меняет ORM/API и не запускает периодическую команду. Это оставляет зависимости A2-02 на импорт задач A3-02 и интеграцию A1 вне данного изменения.

## Контракты и данные

- Новых HTTP/event контрактов, таблиц и миграций нет.
- `ClockSnapshot` отображает нужные clock-поля run и принимает string-enum статусы.
- Naive timestamps, длительность ≤ 0, отрицательные/несогласованные паузы и движение времени назад отклоняются.
- Интеграционный потребитель должен вызвать проверку clock и сохранение посылки в одной короткой транзакции; этот race guard здесь не реализован.

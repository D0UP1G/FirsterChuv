## Сверка с требованиями

Срез поддерживает trusted actor/reason и command-key retry для M08/T11. Pure existing guards продолжают защищать no-score-carry/downstream rules. Это не production idempotency: in-memory tuple не выдерживает process restart/concurrency. Persisted receipts, effect, timer/run mutation и event должны позже коммититься атомарно. Полная T11/T20 и M08 acceptance остаются открыты.

Текущая helper policy scopes key как `(match_id, command_id)` и включает actor/action/reason/arguments в intent fingerprint. Это internal core convention; API endpoint должен подтвердить/соблюсти ту же scope при CONNECT. В общий контракт эта новая convention не внесена.

## Цель и исходное состояние

ROADMAP v3 отмечает, что private artifact language IDs типа list/dict вызывают сырой `TypeError`. Исправить валидацию до внешнего importer, не менять внутренний формат, официальный пакет, общие контракты или код соседних агентов. До правок проверены обязательные проектные документы, карточка агента 3, требования P01/P02/E02/S01, страницы 5–7 кейса, parallel contracts, architecture decisions, GitFlow, текущие refs и P3-02 аудиты. Checkout был чистым на `feature/problem-management-api`, HEAD совпадал с базой.

## Выполненные изменения

- `backend/apps/problems/bundle.py`: добавлена типизированная проверка optional language ID. Разрешены `null` и зарегистрированный строковый ID; массивы, объекты и незарегистрированные ID отклоняются как `ProblemBundleError`. Проверка применяется к checker, validator и reference до словарного lookup.
- `backend/apps/problems/tests/test_bundle.py`: добавлены синтетические invalid-manifest cases для JSON-массивов и объектов во всех трёх полях artifact language ID.
- `context/agents/agent-3.md`: записаны task ID, статус, ветка, base SHA, план до edit и завершённые локальные проверки.
- Общие контракты, API, модели, миграции и чужие файлы не менялись.

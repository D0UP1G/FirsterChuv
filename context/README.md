# Общий контекст для совместной работы

Эта папка помогает следующему агенту продолжить работу без пересказа чата. Она содержит фактический статус, закреплённые требования команды и историю работы. Технические контракты находятся в `docs/architecture/`.

| Файл/папка | Назначение | Кто меняет |
|---|---|---|
| [PROJECT.md](PROJECT.md) | Цель, подтверждённые решения команды, ограничения | Координатор при изменении требований |
| [STATE.md](STATE.md) | Состояние интегрированной версии и следующие общие шаги | Агент 1 при интеграции |
| [agents/](agents/README.md) | Текущая задача, ветка, блокеры каждого агента | Каждый агент свою карточку |
| [audits/](audits/README.md) | Отдельный аудит каждой рабочей сессии | Автор сессии, добавлением нового файла |

Перед началом прочитать `AGENTS.md`, проверить своё назначение в `ROADMAP.md`, затем актуальную ветку и код. После сессии добавить аудит, обновить собственную карточку и передать конкретный следующий шаг.

Если в двух документах разные факты, проверить ветку и дату. Для требований источник истины: текущая инструкция команды и матрица кейса. Для текущего состояния источник истины: реально интегрированный код и результаты проверок. Для контрактов: архитектурные документы и реализованная OpenAPI-схема; расхождение исправляется в одном PR с изменением API.

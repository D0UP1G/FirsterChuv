# FirsterChuv 0.1.0

Первый выпуск платформы блиц-турниров 1×1 по спортивному программированию. Основан на интеграционном `develop`, включающем турнир/приглашения, сетку и admin-команды, рабочее место участника, очередь и Docker judge worker, результаты OK/WA и публичную карту с SSE.

## Запуск

Следуйте [быстрому старту](../../README.md#быстрый-старт-docker-всё-включено) и [runbook](../operations/runbook.md). Для реальной проверки требуется Docker Engine/Compose и Linux-контейнеры. Локальные demo-аккаунты допустимы только при `DJANGO_DEBUG=true`; не используйте их для общего или публичного размещения.

## Проверенное состояние

- CI на release PR должен пройти все 5 checks на точном release head: `backend`, `contracts-and-common-imports`, `domain`, `frontend`, `sandbox-unit`.
- В [evidence реальных вердиктов](../quality/evidence/2026-10-10T082341+0300-A5-real-verdicts.md) подтверждены OK и WA от Docker worker и анонимный публичный snapshot без приватных данных.
- Browser evidence подтверждает основной путь авторизации, приглашения, запуска матча, редактора и снимка зрителя.

## Известные ограничения выпуска

Этот релиз публикуется по прямому поручению команды; он не является заявлением, что полный кейс или обязательный MVP принят. На дату подготовки остаются не подтверждены:

- полная M0 приёмка на одном SHA, продвижение победителя и автоматическое завершение матча;
- реальные CE/TL/ML/RE и враждебные/restart проверки песочницы;
- все сценарии T01–T21 и полная живая SSE приёмка;
- официальный пакет задач организаторов: пакет и README не предоставлены.

Смотрите актуальные [результаты приёмки](../quality/mvp-acceptance.md), [M0 gates](../quality/m0-demo.md) и [операционный runbook](../operations/runbook.md). Не публикуйте открытый demo endpoint без HTTPS ingress и настройки секретов/доступов.
